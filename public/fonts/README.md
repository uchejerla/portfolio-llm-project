# Self-hosted interface fonts

These files are the Latin subsets of the fonts used by the Portfolio Studio interface:

- **Inter** — https://fonts.google.com/specimen/Inter
- **Instrument Serif** — https://fonts.google.com/specimen/Instrument+Serif
- **JetBrains Mono** — https://fonts.google.com/specimen/JetBrains+Mono

All three are licensed under the SIL Open Font License 1.1. License texts:
[Inter](./inter-OFL.txt), [Instrument Serif](./instrument-serif-OFL.txt),
[JetBrains Mono](./jetbrains-mono-OFL.txt).

The ten portfolio templates load their own display faces from Google Fonts when the exported page is
opened, with system fallbacks.
